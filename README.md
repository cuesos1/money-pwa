# Поток · локальное PWA

Доходы, расходы, распределение денег и примерный план погашения долгов. Статический проект без сборки, зависимостей, банковских подключений и аналитики. Все записи и настройки остаются в браузере на устройстве.

## Локальный запуск

Распакуйте архив, откройте терминал в папке проекта и выполните при установленном Python 3:

```sh
python -m http.server 8080 --bind 127.0.0.1
```

На Windows также подходит `py -m http.server 8080 --bind 127.0.0.1`. Откройте http://localhost:8080. Остановка раздачи файлов: Ctrl+C. Это раздача статических файлов, не сервер финансовых данных.

Не открывайте `index.html` двойным щелчком: при `file://` установка и service worker недоступны. На телефоне обычный HTTP по адресу компьютера также не заменяет HTTPS. Исключение localhost действует только на самом устройстве, где запущена раздача файлов.

## Размещение на GitHub Pages / HTTPS

1. Создайте публичный репозиторий GitHub, например `money-pwa`.
2. Add file → Upload files: загрузите содержимое папки проекта вместе с папкой `icons`. `index.html` должен лежать в корне репозитория. README и `verify.cjs` можно не публиковать.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Дождитесь ссылки `https://ВАШ-ЛОГИН.github.io/money-pwa/`.
5. Откройте её с сетью и дождитесь «Готово офлайн».

Можно использовать любой обычный статический HTTPS-хостинг. Поддерживаются корень и подпапка; открывайте адрес с завершающим `/`. Все пути относительные. Хостинг должен отдавать `.js` как JavaScript, `.webmanifest` как `application/manifest+json` или `application/json`, PNG как `image/png`. Для `sw.js` желательно `Cache-Control: no-cache`.

На Android / Chrome: «Установить» в приложении, если доступно, или пункт установки в меню браузера. На iPhone / Safari: Поделиться → На экран «Домой»; при необходимости включите «Открывать как веб-приложение». Компьютерные Chrome / Edge предлагают установку в меню или адресной строке. Конкретная установка зависит от ОС и браузера.

После первой успешной загрузки расчёт, настройки и история работают без сети. Очистка кеша может потребовать повторной загрузки с интернетом.

## Как пользоваться

### Доходы и расходы

- «Распределить»: введите доход, выберите дату (по умолчанию сегодня), посмотрите суммы и нажмите «Записать доход». Пробный ввод не сохраняется. После записи дата возвращается к сегодняшней.
- «Записать расход»: сумма, активная категория, необязательная заметка до 120 символов и дата. Отрицательные суммы и будущие даты не принимаются.
- «История»: 7 дней, текущий и прошлый месяц, текущий год, всё время или свои даты включительно. Последние 7 дней — сегодня и шесть предыдущих календарных дней. Год — с 1 января по сегодня. Даты считаются по часовому поясу устройства.
- Под каждой записью есть «Изменить дату» и «Удалить». Удаление требует подтверждения. Изменение даты обновляет принадлежность к периоду, сохраняя сумму и первоначальное распределение. Удаление необратимо.
- Остатки относятся к выбранному периоду и не являются банковским балансом. Отрицательные остатки допустимы. Начальные остатки из прошлых периодов не переносятся.
- Перевод между своими счетами, пополнение резерва и распределение дохода — не расходы. Покупку записывайте по назначению. Если записать и покупку с кредитки, и погашение долга, сумма расходов включает оба движения.

Суммы рассчитываются в копейках. После округления остаток получает категория с наибольшей дробной частью, при равенстве — первая по порядку. Сумма карточек всегда совпадает с доходом. Ввод: от 0 до 1 000 000 000 ₽, до двух знаков после запятой; доход/расход для записи должен быть больше нуля.

### Настройки

- «Вид»: название внутри приложения, светлая / тёмная / системная тема, четыре цвета акцента. Можно отключить подробные суммы, пояснения, график или анимации. Системная настройка уменьшения движения также учитывается. Название установленного приложения остаётся «Поток».
- «Категории»: название, значок, целая доля 0–100% и переключатель использования. Сумма активных долей — ровно 100%. До 12 категорий. Неактивная категория имеет 0%, но её история остаётся доступной. Категории не удаляются из базы, чтобы сохранить связи старых записей.
- Кнопка возврата 35/40/10/15 включает четыре исходные категории и отключает дополнительные. Она не удаляет историю и не меняет ранее записанные суммы.
- Изменения применяются и сохраняются только кнопкой «Сохранить настройки». Вид можно предварительно посмотреть; закрытие меню отменяет несохранённые изменения.

### Долги и прогноз

Для каждой кредитки, кредита, ипотеки или долга без процентов укажите:

1. Название и тип.
2. Текущий остаток долга.
3. Годовую ставку (для долга без процентов — 0).
4. Минимальный ежемесячный платёж.
5. Плановый фиксированный ежемесячный платёж, не меньше минимального.

Также нужен ожидаемый доход в месяц и категория, на которую выделяются деньги для платежей. До 12 долгов.

«Рассчитать план» покажет сумму минимумов, сумму плановых платежей, необходимый процент от месячного дохода, срок для каждого долга и примерную переплату. Процент округляется вверх до целого, чтобы бюджет не оказался ниже плановых платежей. Например, 10 000 ₽ платежей при доходе 100 000 ₽ — 10%.

«Применить процент» меняет только черновик распределения: доля долгов становится рассчитанной, остальные активные доли пересчитываются пропорционально. Нужно сохранить настройки. Платежи больше дохода и платежи, которые не погашают долг, не предлагаются для применения. При непостоянном доходе рассчитанная доля от отдельных поступлений не гарантирует достаточный ежемесячный платёж.

Прогноз — модель фиксированных ежемесячных платежей. Каждый месяц начисляется `остаток × годовая ставка / 12`, проценты округляются до копейки, затем вносится платёж. Последний платёж ограничен остатком с процентами. Первый платёж предполагается через месяц. Для нулевой ставки начислений нет. Если платёж не больше начальных месячных процентов, срок не вычисляется. Расчёт ограничен 1200 месяцами.

Не учитываются ежедневное начисление, комиссии, страховки, льготный период, новые покупки, изменение ставки, уменьшение банковского минимума и особенности досрочного погашения. Для ипотеки результат относится к заданному фиксированному платежу, а не заменяет договорный график. Остатки долгов обновляются вручную: запись расхода не уменьшает долг автоматически. Это отдельный план, не синхронизация с банком.

Для сценария без долгов выключите «Есть задолженности» и нажмите «Перераспределить без долгов», затем сохраните. Категория платежей отключится, её доля перейдёт к другим активным категориям пропорционально. Записи и сохранённый список долгов не удаляются.

## Хранение и обновление

История и новые настройки находятся в локальной IndexedDB `money-pwa.history`. Старые настройки процентов и темы из localStorage переносятся при первом запуске этой версии. Старая история не переписывается и не удаляется; исходные четыре категории получают постоянные идентификаторы. Новые доходы сохраняют снимок названий, долей и сумм. Переименование или отключение категории не меняет распределение старых доходов.

Настройки и записи сохраняются транзакциями. Если настройки изменились в другой вкладке, запись/сохранение по устаревшей версии отклоняется с сообщением. Новая версия базы закрывает старые подключения. При повреждённых данных исходные записи сохраняются, но не включаются в итоги.

Для обновления опубликованного приложения:

1. Загрузите полный комплект новых файлов на прежний адрес сайта с заменой, включая `sw.js` и `icons`.
2. Откройте приложение с интернетом, чтобы загрузился новый service worker.
3. Закройте все окна/вкладки приложения и откройте снова. Если старая версия осталась, повторите после окончания публикации Pages.
4. Старые варианты иконок на GitHub можно удалить; в новом архиве одна актуальная иконка в 180/192/512 px.

Кеш этой версии — `money-pwa-v7`. При самостоятельных изменениях файлов увеличьте номер, например до `money-pwa-v8`. Полный комплект нужно загрузить до активации. Версия установленной иконки/названия обновляется по правилам браузера и ОС, иногда с задержкой.

**Не очищайте данные сайта ради обновления: это удаляет всю историю, настройки и планы долгов.** Облачной копии и синхронизации нет. Данные привязаны к адресу сайта и профилю браузера. Смена адреса, приватный режим или отдельное хранилище установленного приложения могут дать пустую историю. Не устанавливайте заново и не удаляйте приложение ради смены иконки, не убедившись в сохранности данных.

Более старые выпуски приложения открывали базу версии 1; после обновления база версии 2. Возврат старых файлов не понижает версию базы и может сделать запись недоступной. Для исправления верните актуальный комплект, не удаляя базу. Исходные старые записи сохранены в том же хранилище.

Приложение не отправляет доходы, заметки, категории и долги на хостинг. Хостинг получает только запросы статических файлов и может вести стандартные журналы обращений. В проекте нет внешних шрифтов, скриптов, аналитики или запросов финансовых данных.

## Проверка

При установленном Node.js: `node verify.cjs`. Проверяются суммы, копейки, периоды, старый и новый формат записей, категории, настройки, проценты долгов и прогноз погашения.

Также проверено в настольном Edge с мобильным экраном 390 px и 320 px: перенос базы версии 1 без изменения старых записей; новые категории; запись/редактирование/удаление дохода; собственные списки выбора; сценарии с долгами и без; сохранение темы; офлайн-перезапуск и запись доходов/расходов; отсутствие внешних запросов и горизонтальной прокрутки. Установку и отображение новой иконки на реальном iPhone/Android нужно проверить отдельно.


## Обновление оформления v7

Более насыщенный фон, цветные стеклянные карточки, мягкие отражения, объёмные кнопки и новые контурные иконки. Финансовые расчёты, база и сохранённые предпочтения не меняются. Иконки интерфейса: Lucide 1.8.0, выбранные из каталога https://21st.dev/community/icons/lucide; в проект включены только 16 SVG-определений (~5 KB) из официального установленного пакета, без библиотеки целиком. Лицензия сохранена в ICON-LICENSE.txt. Ресурс icon-data.js нужно публиковать вместе с остальными файлами.

Эффект стекла реализован обычным CSS: статические градиенты и ограниченный blur 12–14 px. У карточек нет backdrop blur, нет WebGL, внешних шрифтов или постоянно анимируемых фонов. При отключении прозрачности или отсутствии backdrop-filter используется непрозрачная подложка. Плавные переходы учитывают настройки уменьшения движения. Реальная плавность зависит от устройства; проверка в настольном браузере не заменяет измерение на слабом телефоне.
