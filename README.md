# Распределение денег

Готовое статическое PWA на русском: кредитка 35%, жизнь 40%, резерв 10%, свободные 15%. Без сборки, зависимостей, банков, аналитики и внешних запросов.

## Запуск на компьютере

1. Распакуйте проект и откройте терминал в папке `money-pwa`.
2. Если установлен Python 3, выполните:

   ```sh
   python -m http.server 8080 --bind 127.0.0.1
   ```

   На Windows также можно использовать `py -m http.server 8080 --bind 127.0.0.1`.
3. Откройте http://localhost:8080 в браузере. Дождитесь надписи «Готово к работе офлайн».
4. После первого открытия приложение работает без сети. Остановить локальную раздачу файлов: Ctrl+C. Уже открытый или установленный браузером экземпляр сможет использовать кеш; его очистка потребует повторного запуска.

Это локальная раздача статических файлов для запуска, а не сервер приложения. Двойной щелчок по `index.html` не включает service worker и установку. Не открывайте проект как `file://`.

## HTTPS-хостинг и установка на телефон

1. Загрузите содержимое папки `money-pwa` на обычный статический HTTPS-хостинг: `index.html`, все скрипты, CSS, `sw.js`, `manifest.webmanifest` и папку `icons`. README и проверочный скрипт можно не загружать.
2. Сайт может жить в корне или подпапке, например `https://example.com/money/`. Открывайте адрес с завершающим `/`. Все пути относительные.
3. Хостинг должен отдавать `.js` как JavaScript, `.webmanifest` как `application/manifest+json` или `application/json`, PNG как `image/png`. Нужен действительный HTTPS. Для `sw.js` желательно `Cache-Control: no-cache`.
4. Откройте сайт с сетью один раз и дождитесь готовности офлайн-режима.
5. Android / Chrome: кнопка «Установить приложение», если браузер её предоставляет, или пункт установки в меню браузера. iPhone / Safari: «Поделиться» → «На экран “Домой”» (в новых версиях iOS при необходимости включите «Открывать как веб-приложение»). На компьютере Chrome / Edge предлагают установку в адресной строке или меню.

Установка зависит от браузера. Обычный HTTP по адресу компьютера в домашней сети не заменяет HTTPS для телефона. `localhost` — исключение только на том устройстве, где запущена раздача файлов.

## Использование и данные

- Введите сумму, например `17350` или `17 350,50`. Диапазон: 0–1 000 000 000 ₽, до двух знаков после запятой.
- Шестерёнка открывает настройки. Каждый процент — целое число от 0 до 100; сумма должна быть 100. Нажмите «Сохранить», чтобы применить. «Сбросить» сразу сохраняет 35/40/10/15.
- Деньги рассчитываются в копейках. Остаток округления получают категории с наибольшей дробной частью; при равенстве — в порядке карточек. Сумма карточек всегда равна доходу. Для 17 350 ₽: 6 072,50 / 6 940 / 1 735 / 2 602,50 ₽.
- В `localStorage` сохраняются проценты и тема. Доход сохраняется только после нажатия «Записать доход», в локальной IndexedDB браузера, вместе с датой и распределением на момент записи. Пробный ввод не сохраняется. При недоступности хранилища приложение сообщает об ошибке; расчёт продолжает работать.
- Статистика: последние 7 дней (сегодня и шесть предыдущих), текущий календарный месяц, прошлый месяц, текущий год, всё время и свои даты включительно. Даты считаются по часовому поясу устройства. Все записи сохраняются в локальной базе, даже если не входят в выбранный период.
- «Записать расход»: сумма, одна из четырёх категорий, необязательная заметка до 120 символов и дата не позже сегодня. Ошибочную запись можно удалить в списке за выбранный период с подтверждением.
- Категории: «Жизнь» — продукты, жильё, транспорт; «Свободные» — покупки и развлечения; «Резерв» — фактическая непредвиденная трата; «Кредитка» — погашение долга. Перевод денег между своими счетами и пополнение резерва не записывайте как расход. Покупку с кредитки относите к назначению; если также записать погашение долга, общий расход отражает оба движения, а не только стоимость покупки.
- Итоги показывают доходы, расходы, разницу и остаток по каждой категории за период. Отрицательный остаток допустим: в этом периоде потрачено больше, чем выделено. Это учёт введённых операций, не банковский баланс; деньги из предыдущих периодов не переносятся в остаток выбранного периода. Историческое распределение доходов не меняется при изменении процентов. График показывает доходы; в длинных периодах дни объединяются в группы.
- Кнопка луны/солнца переключает тему. До первого переключения используется тема устройства, затем сохраняется твой выбор.
- Нет отправки дохода и процентов, аналитики, банковских интеграций или серверной базы. При загрузке с HTTPS-хостинга браузер запрашивает файлы сайта; сам хостинг может вести обычные журналы обращений.
- Данные привязаны к адресу сайта и профилю браузера. Очистка данных сайта удаляет настройки, ВСЮ историю доходов и офлайн-кеш. Резервного копирования и синхронизации нет. Данные разных браузеров и устройств не объединяются; установленное приложение может иметь отдельное хранилище в зависимости от платформы. В приватном режиме хранение и установка могут быть ограничены.

## Обновление

При изменении файлов измените `CACHE` в `sw.js`, например на `money-pwa-v6`, и загрузите полный комплект. Новая версия активируется после закрытия всех открытых вкладок/окон приложения и повторного открытия. Не удаляйте предыдущие файлы, пока новый комплект не загружен. Используйте отдельный адрес/подпапку для этого PWA, без другого service worker с пересекающейся областью действия.

## Проверка

При установленном Node.js выполните `node verify.cjs`. Проверяются ввод, проценты, точность распределения и наличие ресурсов манифеста/кеша.

Ручная проверка: ввести сумму; сохранить 25/25/25/25; перезагрузить; убедиться, что 99% не сохраняются; сбросить проценты; после готовности офлайн-режима отключить сеть и перезагрузить сайт. Расчёт и настройки должны работать. Визуально проверить экран телефона и установку в своём браузере.

## Обновление уже опубликованной версии

В GitHub открой репозиторий → Add file → Upload files и загрузи новые файлы с заменой. В этом комплекте кеш уже обновлён до v5. Сохраняй прежний адрес сайта: тогда настройки и история остаются на месте. Открой приложение с интернетом, затем закрой все его окна и вкладки, и открой заново. Если всё ещё виден старый интерфейс, повтори после завершения публикации Pages. Не очищай данные сайта ради обновления — это удалит историю.

## Пример

Получил 10 000 ₽ → ввёл сумму → «Записать доход». Купил продукты за 850 ₽ → «Записать расход» → 850 → «Жизнь» → заметка «Продукты» → «Записать расход». В категории «Жизнь»: выделено 4 000 ₽, потрачено 850 ₽, осталось 3 150 ₽ за этот период.

Иконка обновлена: графитовый кошелёк из дымчатого стекла с синими акцентами, отдельные PNG 180/192/512 px. Скругление внешней формы задаёт телефон. Установленная иконка обновляется по правилам браузера/ОС, иногда с задержкой; не очищайте данные сайта ради её обновления.
