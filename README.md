# Распределение денег

Готовое статическое PWA на русском: кредитка 35%, жизнь 40%, резерв 10%, свободные 15%. Без сборки, зависимостей, банков, аналитики и внешних запросов.

## Запуск на компьютере

1. Распакуйте проект и откройте терминал в папке `money-pwa`.
2. Если установлен Python 3, выполните:

   ```sh
   python -m http.server 8080 --bind 127.0.0.1
   ```

   На Windows также можно использовать `py -m http.server 8080 --bind 127.0.0.1`.
3. Откройте http://localhost:8080 в браузере. Дождитесь надписи «Готово к работе офлайн».
4. После первого открытия приложение работает без сети. Остановить локальную раздачу файлов: Ctrl+C. Уже открытый или установленный браузером экземпляр сможет использовать кеш; его очистка потребует повторного запуска.

Это локальная раздача статических файлов для запуска, а не сервер приложения. Двойной щелчок по `index.html` не включает service worker и установку. Не открывайте проект как `file://`.

## HTTPS-хостинг и установка на телефон

1. Загрузите содержимое папки `money-pwa` на обычный статический HTTPS-хостинг: `index.html`, оба скрипта, CSS, `sw.js`, `manifest.webmanifest` и папку `icons`. README и проверочный скрипт можно не загружать.
2. Сайт может жить в корне или подпапке, например `https://example.com/money/`. Открывайте адрес с завершающим `/`. Все пути относительные.
3. Хостинг должен отдавать `.js` как JavaScript, `.webmanifest` как `application/manifest+json` или `application/json`, PNG как `image/png`. Нужен действительный HTTPS. Для `sw.js` желательно `Cache-Control: no-cache`.
4. Откройте сайт с сетью один раз и дождитесь готовности офлайн-режима.
5. Android / Chrome: кнопка «Установить приложение», если браузер её предоставляет, или пункт установки в меню браузера. iPhone / Safari: «Поделиться» → «На экран “Домой”» (в новых версиях iOS при необходимости включите «Открывать как веб-приложение»). На компьютере Chrome / Edge предлагают установку в адресной строке или меню.

Установка зависит от браузера. Обычный HTTP по адресу компьютера в домашней сети не заменяет HTTPS для телефона. `localhost` — исключение только на том устройстве, где запущена раздача файлов.

## Использование и данные

- Введите сумму, например `17350` или `17 350,50`. Диапазон: 0–1 000 000 000 ₽, до двух знаков после запятой.
- Шестерёнка открывает настройки. Каждый процент — целое число от 0 до 100; сумма должна быть 100. Нажмите «Сохранить», чтобы применить. «Сбросить» сразу сохраняет 35/40/10/15.
- Деньги рассчитываются в копейках. Остаток округления получают категории с наибольшей дробной частью; при равенстве — в порядке карточек. Сумма карточек всегда равна доходу. Для 17 350 ₽: 6 072,50 / 6 940 / 1 735 / 2 602,50 ₽.
- В `localStorage` сохраняются только проценты. Введённый доход не сохраняется. При запрете хранилища расчёт продолжает работать, а интерфейс сообщает, что настройки не сохранены.
- Нет отправки дохода и процентов, аналитики, банковских интеграций или серверной базы. При загрузке с HTTPS-хостинга браузер запрашивает файлы сайта; сам хостинг может вести обычные журналы обращений.
- Данные привязаны к адресу сайта и профилю браузера. Очистка данных сайта удаляет настройки и офлайн-кеш. В приватном режиме хранение и установка могут быть ограничены.

## Обновление

При изменении файлов измените `CACHE` в `sw.js`, например на `money-pwa-v2`, и загрузите полный комплект. Новая версия активируется после закрытия всех открытых вкладок/окон приложения и повторного открытия. Не удаляйте предыдущие файлы, пока новый комплект не загружен. Используйте отдельный адрес/подпапку для этого PWA, без другого service worker с пересекающейся областью действия.

## Проверка

При установленном Node.js выполните `node verify.cjs`. Проверяются ввод, проценты, точность распределения и наличие ресурсов манифеста/кеша.

Ручная проверка: ввести сумму; сохранить 25/25/25/25; перезагрузить; убедиться, что 99% не сохраняются; сбросить проценты; после готовности офлайн-режима отключить сеть и перезагрузить сайт. Расчёт и настройки должны работать. Визуально проверить экран телефона и установку в своём браузере.
